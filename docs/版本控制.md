## 回退方式

**只回退某个文件（推荐，最安全）：**

```bash
git checkout v3.2-case-visuals -- the_last_resourse/cases/pump-diagnosis-cv/demo/demo.js
```

**整体切到某个版本查看（不会丢工作区修改，但会处于 detached HEAD）：**

```bash
git checkout v3.1-explore
# 看完回到当前分支
git checkout feature/case-visuals
```

**彻底丢弃当前工作区、回到某个标签（危险，先确认没有要保留的修改）：**

```bash
git reset --hard v3.2-case-visuals
```

**从当前版本拉一个新分支做实验：**

```bash
git checkout -b feature/next-idea
```
