01 · 落物描述结构化现场文本 → 10 个字段

现场先给一段描述。解析器把它拆成形态、外径、内径、长度、井斜、落底三态、材质、卡阻、循环、套管，然后做质控：哪些字段缺失、哪些只能沿用当前值、哪些不确定性（落底未知、内径未给出）会直接改变候选集合。

等待解析：也可以直接拖动上方参数，字段来源会标成「手工」。
—
02 · 工具知识图谱与硬约束先排除，再排序

工具知识表不是一张打分表，而是一组可判定的物理条件。这里按顺序过 8 道门：鱼顶可达 → 通径/单边间隙 → 可捞区间 → 材质 → 井斜 → 循环 → 落底 → 咬合长度。任何一道不通过就直接标「不可用」，不进入学习排序，也不靠扣分蒙混。

图谱：5 类落物 × 11 件打捞工具 × 2 件工序工具；边 = 形态适用度 / 可捞区间 / 工况条件。

04 · 方案组装主工具 + 备选 + 解卡/磨铣

排序第一不等于「只带一件工具」。方案要给出主工具、备选、工具串、作业顺序和风险前提：落底未知先打印确认并保留两分支；砂卡/水泥卡追加震击器 + 安全接头；没有可行打捞工具时，转套铣/磨铣工序，而不是硬推一个物理上不可行的选项。

05 · 反馈与价值回写 → 在线更新 → 重训

模型的最后一个输入是现场结果。工程师确认「这次选用成功/失败」后，工具成功率按贝叶斯平滑更新，样本追加进训练集并重训；下一轮的权重会变，日志里能看见变化。
