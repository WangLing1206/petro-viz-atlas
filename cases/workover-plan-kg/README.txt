修井作业方案智能推荐 · 案例包
==============================

这是什么
--------
一个可以直接上传到「石油勘探开发智能化可能性地图」网站的完整案例包：
讲解内容在 case.json，可运行示范在 demo/ 文件夹里。

绑定场景
--------
10 修井 / wo1 修井作业方案智能推荐（方法标签：KG 知识图谱 + NLP 自然语言处理）

怎么用
------
1. 打开网站，点右上角「＋ 添加案例」；
2. 把本文件夹（workover-plan-kg）整个拖进弹窗，或点「选择文件夹」；
3. 右侧逐项校验，全绿后点「校验并添加」；
4. 页面自动跳到「修井 · 修井作业方案智能推荐」场景，三个 tab 立即出现。

文件清单
--------
  case.json          清单：元信息 + 专业背景 + 案例流程（必需）
  demo/index.html    示范页（整页模式，沙箱 iframe 中运行）
  demo/demo.css      示范页样式（案例包自带皮肤）
  demo/demo.js       示范脚本：加权相似度检索 + 图谱路径高亮
  README.txt         本文件

示范内容
--------
  14 口历史修井作业组成的案例库；
  拖动「故障现象 / 套管内径 / 井深 / 含水 / 出砂」五个井况输入，
  看加权相似度检索怎么挑出相似作业、按「相似度 × 历史成功率」
  组装候选方案；点方案或历史作业行，图谱上会点亮命中路径，
  下方给出相似度的分项拆解。

想改成你自己的案例
------------------
改 case.json 里的 id / sceneId / title 和三块正文即可；
demo/ 换成你自己的页面也一样能传。
