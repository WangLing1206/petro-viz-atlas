压裂参数智能优化 · 案例包
==========================

这是什么
--------
一个可以直接上传到「石油勘探开发智能化可能性地图」网站的完整案例包：
讲解内容在 case.json，可运行示范在 demo/ 文件夹里。

绑定场景
--------
10 增采 / e1 压裂参数智能优化（方法标签：OPT 智能优化）

怎么用
------
1. 打开网站，点右上角「＋ 添加案例」；
2. 把本文件夹（frac-optimize-opt）整个拖进弹窗，或点「选择文件夹」；
3. 右侧逐项校验，全绿后点「校验并添加」；
4. 页面自动跳到「增采 · 压裂参数智能优化」场景，三个 tab 立即出现。

文件清单
--------
  case.json          清单：元信息 + 专业背景 + 案例流程（必需）
  demo/index.html    示范页（整页模式，沙箱 iframe 中运行）
  demo/demo.css      示范页样式（案例包自带皮肤）
  demo/demo.js       示范脚本：模拟器响应面 + GP 代理 + EI 贝叶斯优化
  README.txt         本文件

示范内容
--------
  一个带压力硬约束的产能响应面（单峰脊线 + 局部次优 + 测量噪声）：
  · 两个设计变量：排量 Q（3—8 m³/min）、砂比 S（5—25%）；
  · 三种采样策略同起点、同预算并行推进（每轮各评估 3 个新点）：
    随机采样 / 7×7 网格扫描 / 贝叶斯优化（平方指数核 GP + EI）；
  · 等高线图（真实面 + 代理预测面 + 压力超限区）、采样点按轮次着色、
    推荐点星标与十字线；
  · 收敛曲线（已评估次数 → 当前最优产能）+ 帕累托前沿（产能 vs 砂量）
    + 推荐方案卡（预测区间、砂量、压力余量、与邻井经验方案对比）；
  · 30 次模拟的预算内：贝叶斯 96.0 / 网格 89.5 / 随机 83.7，
    贝叶斯 12—15 次即可逼近最优，且对约束的无效试探为 0 次。
  点「运行一轮优化」逐轮推进，「自动跑到收敛」一键跑完，
  噪声滑杆拉大可以看测量噪声怎么拖慢代理模型。

想改成你自己的案例
------------------
改 case.json 里的 id / sceneId / title 和三块正文即可；
demo/ 换成你自己的页面也一样能传。
若要把示范换成别的优化问题，只动 demo/demo.js 顶部的
「模拟器响应面」（piTrue / pres）与变量区间四行常量即可，
代理模型、EI 选点与三种策略的对照逻辑都不用改。
