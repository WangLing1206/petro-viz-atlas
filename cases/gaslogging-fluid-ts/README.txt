气测异常智能解释 · 案例包
==========================

这是什么
--------
一个可以直接上传到「石油勘探开发智能化可能性地图」网站的完整案例包：
讲解内容在 case.json，可运行示范在 demo/ 文件夹里。

绑定场景
--------
04 录井 / m2 气测异常智能解释（方法标签：TS 时序分析）

怎么用
------
1. 打开网站，点右上角「＋ 添加案例」；
2. 把本文件夹（gaslogging-fluid-ts）整个拖进弹窗，或点「选择文件夹」；
3. 右侧逐项校验，全绿后点「校验并添加」；
4. 页面自动跳到「录井 · 气测异常智能解释」场景，三个 tab 立即出现。

示范内容
--------
  3000—4200 m 的合成气测资料（全烃 + C1—C5 组分 + 钻时，2.5 m 一点），
  里面埋了 气层 3280—3325 m、油层 3560—3665 m、薄油层 3740—3770 m、
  水层 3895—3975 m 四个显示段，并叠加背景气漂移、接单根窄峰与噪声。
  算法真的在跑：滑动分位数基线校正 → MAD 估计噪声 σ → 峰高（k·σ）与
  持续长度双判据分段 → 段内组分比（峰区加权中位数）→ Pixler 双对数
  图版分区，输出每段的油 / 气 / 水结论与置信度，并与合成真值对账。

  四个滑杆：峰高阈值 k·σ、最小持续长度、基线窗口、分位数 q；
  两组按钮：数据工况（正常钻进 / 加重钻井液 / 接单根频繁）、
  基线方法（滑动分位数 / 滑动均值 / 不校正）；
  两个开关：接单根与背景漂移、组分曲线 C1—C5。

  四个可视区：
  ① 主图：全烃、C1—C5（对数轨）、钻时共用一条深度轴，检出段着色，
     背景气基线虚线，鼠标停在曲线上可读该深度的数值；
  ② 基线校正前后：左图实测曲线与估计基线，右图校正后曲线与阈值线、
     检出段实心块，合成真值里没被检出的层段用红框标出；
  ③ Pixler 双对数图版：油区 / 气区 / 水区三个分区 + 各段组分比落点，
     落点随参数实时移动，点结论表任意一行会放大地对应的点；
  ④ 结论表 + 判据统计：深度区间、峰值、C1/C2、C1/C3、结论、置信度。

  可以试着验证的三件事：
  · 峰高阈值推到 6σ —— 薄油层的显示被滤掉，层段命中率从 4/4 掉到 3/4；
  · 最小持续降到 1—2 点 —— 接单根窄峰全部变成假异常段，误报段数暴增；
  · 基线方法换成「滑动均值」或「不校正」—— 峰被削平 / 背景气抬升被当成
    异常，且弱层的组分比被背景气拉向气区，油层被读成气层。

------------------
