管道泄漏智能检测 · 案例包（负压波定位 + 流量平衡交叉验证）
==========================================================

这是什么
--------
一个可以直接上传到「石油勘探开发智能化可能性地图」网站的完整案例包：
讲解内容在 case.json，可运行示范在 demo/ 文件夹里。

绑定场景
--------
12 运输 / t1 管道泄漏智能检测（方法标签：TS 时间序列）

怎么用
------
1. 打开网站，点右上角「＋ 添加案例」；
2. 把本文件夹（pipeline-leak-ts）整个拖进弹窗，或点「选择文件夹」；
3. 右侧逐项校验，全绿后点「校验并添加」；
4. 页面自动跳到「运输 · 管道泄漏智能检测」场景，三个 tab 立即出现。

文件清单
--------
  case.json          清单：元信息 + 专业背景 + 案例流程（必需）
  demo/index.html    示范页（整页模式，沙箱 iframe 中运行）
  demo/demo.css      示范页样式（案例包自带皮肤）
  demo/demo.js       示范脚本：双站压力合成 + 突变检测 + 时间差定位 + 交叉验证
  README.txt         本文件

示范内容
--------
  120 km 管段的合成数据：24 h 双站压力（10 s 历史库）与 1 s 原始数据流，
  含稳态漂移、噪声、工况扰动（调阀 / 泵切换）与可选泄漏事件。
  控制件：场景（稳态运行 / 调阀扰动 / 启泵扰动 / 泄漏）、泄漏位置 0—100%、
  漏量 0.5—5% 输量、噪声 0.3—3×、触发阈值 0.015—0.09 MPa、
  「工况感知」「流量平衡交叉验证」两个开关、24 h 时间轴播放。
  四张图：管线纵剖面上的负压波传播动画（波前从漏点向两端扩散、先到近端）、
  双站压力与突变指标 S（含阈值线与泄漏色带）、Δt 放大（1 s 原始数据的两端波形）、
  进出站流量差累计（真泄漏持续偏离、工况扰动短时脉冲后回落）。
  算法是真的在跑：滑动窗均值差粗筛 → 回捞 1 s 数据用 S 脉冲质心精定 t1 / t2
  → x = (L + v·Δt)/2 定位 → 流量平衡与工况记录交叉验证 → 给出定位误差、
  检测延迟、误报与漏报计数。

想改成你自己的案例
------------------
改 case.json 里的 id / sceneId / title 和三块正文即可；
demo/ 换成你自己的页面也一样能传。
